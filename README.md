# 🧠 Reverse Engineering Challenges - Eclipse CTF

This repository contains a set of reverse engineering challenges created for **Eclipse CTF @ ENSA Tétouan**.

---

## 📦 Challenges

### 🔹 Challenge 1
- **Name:** Basic Reverse
- **Difficulty:** Easy
- **Description:**
  Analyze the binary and recover the hidden flag.

---

### 🔹 Challenge 2
- **Name:** Obfuscated Logic
- **Difficulty:** Medium
- **Description:**
  The program contains obfuscated logic. Reverse it to find the correct input.

---

### 🔹 Challenge 3
- **Name:** Crack Me
- **Difficulty:** Hard
- **Description:**
  Bypass all checks and retrieve the flag.

---

## 🚀 How to play

1. Download the challenge binaries from the `dist/` folder (or each challenge folder)
2. Use tools like:
   - Ghidra
   - IDA
   - strings
   - ltrace / strace
3. Reverse the logic and find the flag

---

## ⚠️ Rules

- Do not brute force unless explicitly allowed
- No sharing flags during the event
- Respect fair play
